# THÖNDERSTÖRM-addons

Skatteverket (guildskatt, `/skatt`) och Swedbank (guildlån, `/swedbank`) för WoW Forever. De fungerar bara för medlemmar i THÖNDERSTÖRM; för alla andra gör de ingenting.

## Installera med WowUp (rekommenderas)

1. Installera WowUp-CF (https://wowup.io) om du inte redan har det, och välj WoW Forever.
2. Klicka på **Get Addons** och sedan **Install from URL**.
3. Klistra in `https://github.com/methdrugs/guild-addons` och klicka **Import**, sedan **Install**.
4. Klart. WowUp uppdaterar addonsen själv när en ny version kommer.

## Installera för hand

Ladda ner zip-filen under **Releases** till höger, stäng WoW och packa upp. Kopiera mapparna Skatteverket och Swedbank direkt till `Interface\AddOns` i mappen `_forever_`. Vid en uppdatering: ta bort de gamla mapparna och kopiera in de nya.

Din skattehistorik och dina lån sparas i mappen WTF, inte i addon-mapparna, så de finns kvar vid uppdateringar. Ta aldrig bort mappen WTF.
